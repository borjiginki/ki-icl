# Entsorgung + Recycling Zürich — Open Governance Data (OGD)

**Sector:** Cross-Industry · **Industry:** Public Sector

## At a glance

A compliant Open Governance Data solution for the City of Zurich — automated, role-based and secure digital data provisioning for citizens.

## Initial situation

The City of Zurich aimed to enhance public data transparency. Building on its 2012 OGD initiative, reinforced by federal support in 2018, the 2021 city regulations formalized the mandate for secure, accessible data sharing for private individuals.

## Approach

We delivered a strategic roadmap for compliant data provision upon request and implemented an automated system that defined user roles and a verification process, so data could be requested and provided digitally in a secure manner.

## Results

- **Compliance** with data laws and regulations
- **Digitization** of public provision and data accessibility
- **Improved datasets** by integrating reliable data from more sources
- Seamless process to **access data securely**
