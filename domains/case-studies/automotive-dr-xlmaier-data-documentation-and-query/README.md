# Dräxlmaier — Data Documentation and Query

**Sector:** Automotive · **Industry:** Automotive · Supplier

## At a glance

A Microsoft Fabric Lakehouse for Dräxlmaier's 30-year data retention — replacing a strained Oracle database for faster, compliant querying of historical data.

## Initial situation

Strict legal requirements mandate up to 30 years of data retention, producing massive data volumes and increasingly time-consuming queries on the central Oracle database — performance constraints that hindered reliable compliance with SLAs and regulations.

## Approach

To improve performance and scalability, we replicated and transformed data into a Fabric Lakehouse as a more efficient foundation for querying and reporting. The engagement covered architecture design, end-to-end validation from ingestion to consumption and a structured knowledge transfer.

## Results

- Implementation of a **scalable, future-ready data platform** compliant with legal requirements and SLAs
- **Faster, more efficient querying** of historical data
- **Increased performance** and system reliability
