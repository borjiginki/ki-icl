# Galenica — Source Data Ingestion

**Sector:** Cross-Industry · **Industry:** Retail, E-Commerce & Omnichannel

## At a glance

Centralized, metadata-driven ingestion pipelines on Azure Data Factory for Galenica — reusable, low-code and elastically scalable across source systems.

## Initial situation

Data ingestion pipelines at Galenica were siloed across various tools and platforms, creating maintenance challenges and complicating governance.

## Approach

We developed centralized, generic data ingestion pipelines using Azure Data Factory, supporting integration from multiple source systems and formats into Azure Data Lake. The metadata-driven framework allows greater flexibility and efficiency.

## Results

- **Centralized, reusable** data ingestion pipeline
- Seamless ingestion from **multiple source systems and formats**
- **Low-code, UI-based** — easy to interpret and maintain
- **Elastic scalability** that adjusts resources to workload demand
