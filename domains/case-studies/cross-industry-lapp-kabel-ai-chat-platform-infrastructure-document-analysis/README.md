# Lapp Kabel — AI Chat Platform Infrastructure & Document Analysis

**Sector:** Cross-Industry · **Industry:** Industrial Technology

## At a glance

A secure, scalable Azure foundation for LappGPT V2 with Entra ID auth, LLM integration and document-based RAG — delivered in transparent Scrum sprints.

## Initial situation

Lapp aimed to evolve its internal AI, LappGPT, but lacked the technical foundation for secure infrastructure, reliable authentication and modern features such as document-based querying. Architecture, DevOps scalability and secure file handling had to be addressed from scratch.

## Approach

We built the foundation for LappGPT V2 using IaC and DevOps on Azure, with secure Entra ID authentication, a backend for APIs and LLM integration, and a front-end matching Lapp's design. Document-based RAG was added — all delivered in transparent two-week Scrum sprints with regular budget tracking.

## Results

- **Secure, scalable, maintainable** Azure-based infrastructure
- Enabled file upload and **chat-based analysis** via LLMs
- **Early architecture validation** through automation and compliance checks
- Clear documentation and modular delivery for **future flexibility**
