# Galenica — Platform Refactoring with Microsoft Fabric

**Sector:** Cross-Industry · **Industry:** Retail, E-Commerce & Omnichannel

## At a glance

A dbt-based refactoring of Galenica's MS Fabric platform — modular, reusable SQL models that improve collaboration, governance and analysis efficiency.

## Initial situation

Galenica's outdated, over-complicated data platform created collaboration challenges for engineers and analysts. Identifying available, report-ready datasets was difficult, complicating workflows. Galenica needed to simplify onboarding while enabling efficient, barrier-free work.

## Approach

We integrated dbt (Data Build Tool) to streamline SQL-based transformations within MS Fabric. Our modular, reusable design improved maintainability and collaboration. We enhanced data governance while optimizing transformations through database-native processing to minimize unnecessary data movement.

## Results

- Facilitated **collaboration** and efficiency for more effective data analysis
- Enhanced **data governance and security** with built-in testing, documentation and lineage tracking
