# Mercedes-Benz — Taxation Optimization of Vehicles and Components

**Sector:** Automotive · **Industry:** Automotive · Core Functions

## At a glance

A real-time documentation solution for Mercedes-Benz international vehicle taxation — consolidating fragmented component data with a cloud migration path for compliance.

## Initial situation

The client's fragmented legacy system required manual compliance checks and hindered international taxation, with vehicle-component data stored across various files and databases. In its ambition to optimize for international taxation, the system had to be consolidated.

## Approach

We built a solution to document and provide real-time updated data to dismantle and reassemble a vehicle across regions, streamlining costs and complying with various tax laws.

## Results

- Increased **real-time operational updates**
- **Digitization capabilities** developed across shipping and customs domains
- Possible **target solutions** identified and solution paths assessed (OnPrem, Cloud, Vendor-Product)
- A **migration path** conceptualized and delivered with cloud architecture-based solutions
