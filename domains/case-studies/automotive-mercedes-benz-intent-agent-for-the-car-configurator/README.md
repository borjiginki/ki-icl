# Mercedes-Benz — Intent Agent for the Car Configurator

**Sector:** Automotive · **Industry:** Automotive · Sales

## At a glance

An Intent Agent for the Mercedes-Benz car configurator — natural-language, catalog-grounded configuration with kill-switches and ~33% lower token consumption.

## Initial situation

In the Mercedes-Benz online configurator, customers were overwhelmed by the wealth of options and decisions — the path from initial wish to finished configuration was too complex to navigate intuitively, leading to high drop-off rates and missed sales opportunities.

## Approach

We developed an Intent Agent that interprets natural language and steers the configurator end-to-end, from first wish to finished configuration. AI interprets meaning while deterministic code decides what applies; every capability runs with a kill-switch, fallback and confidence threshold, with live verification against real catalog data.

## Results

- **Natural-language configuration** in German and English — typo-tolerant and language-mixed
- **Exclusively catalog-based answers** — no generated options or prices
- **~33% reduced token consumption**, one fewer LLM call per configuration turn, with graceful degradation under load
