# Bayernwerk — Mobile App for Substation Configurator

**Sector:** Power & Utilities · **Industry:** Power & Grid

## At a glance

A mobile substation-configurator app for Bayernwerk — image recognition that auto-extracts device data from scans, removing manual input and speeding grid expansion.

## Initial situation

Bayernwerk AG's substation and power-tower expansion faced slow scaling due to manual data collection.

## Approach

With advanced image recognition, data is now automatically extracted and processed from scanned devices via a mobile substation-configurator app, eliminating manual input.

## Results

- **Automated data extraction** from scanned devices via image recognition
- **Eliminated manual input**
- **Faster scaling** of substation and tower expansion
