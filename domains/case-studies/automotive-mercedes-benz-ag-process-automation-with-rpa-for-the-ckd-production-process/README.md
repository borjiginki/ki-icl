# Mercedes-Benz AG — Process automation with RPA for the CKD production process

**Sector:** Automotive · **Industry:** Automotive · Production

## At a glance

A UiPath RPA bot automating Mercedes-Benz CKD order entry — from 10+ minutes of manual code entry to ~10 seconds with 100% accuracy.

## Initial situation

The CKD process required entering order information into the global ordering (GO) ERP system using data from multiple Excel files — manually entering over 100 three-digit codes, taking more than 10 minutes and prone to error.

## Approach

We developed an RPA solution using UiPath's REFramework. The bot reads order data from Excel, inputs it into the GO system, saves results as PDF and updates the Excel file, leveraging work blocks, state transitions and exception handling for efficiency and accuracy.

## Results

- Data entry reduced from **10+ minutes manually to ~10 seconds** automatically
- **100% accuracy** in entering codes
- Automated generation of updated **Excel and PDF** outputs
- Standardized, scalable process using **UiPath REFramework**
