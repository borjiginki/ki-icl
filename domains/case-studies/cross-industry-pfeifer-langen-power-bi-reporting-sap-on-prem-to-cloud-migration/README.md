# Pfeifer & Langen — Power BI Reporting & SAP On-Prem to Cloud Migration

**Sector:** Cross-Industry · **Industry:** Food Manufacturing

## At a glance

Optimized Power BI reporting and a low-disruption SAP on-prem to cloud migration path, improving report quality and cloud readiness.

## Initial situation

Pfeifer & Langen IT Services (PLITS) provides digital solutions to the group's business customers, using SAP on-premises data stores to build Power BI reports, with substantial processing done via Power BI Dataflows.

## Approach

We enhanced data processing and provisioning by leveraging relevant Power BI Services to improve reporting delivery. In parallel we supported the migration of on-premises SAP data stores to the SAP cloud, ensuring minimal disruption to existing downstream reporting.

## Results

- Optimized **reporting environment** and better-quality products
- Better **user experience**
- Preparatory steps toward **migrating on-prem architecture to cloud**
