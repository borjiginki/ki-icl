# KWS Saat — Automated Invoice Processing

**Sector:** Cross-Industry · **Industry:** Agriculture

## At a glance

An Azure Document AI module in KWS Saat's customer app that auto-extracts invoice data — speeding processing and boosting payback program participation.

## Initial situation

KWS Saat introduced a payback program rewarding farmers for growing certain corn varieties. Invoices proving corn type and quantity had to be submitted — a time-consuming, error-prone manual process.

## Approach

We developed a module for the customer app using Azure Document AI to automatically extract key data (corn type, quantity, amount) from uploaded photos or invoices, reducing manual effort and significantly speeding up processing.

## Results

- Significantly **accelerated processing** and minimized errors via automated data discovery
- **Increased customer satisfaction** through simpler invoice submission
- **Strengthened loyalty** by promoting participation in the payback system
