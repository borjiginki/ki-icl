# OutSystems — User Intent Extraction with a Multi-Agent Network

**Sector:** Cross-Industry · **Industry:** IT

## At a glance

A multi-agent system that turns natural-language input into OutSystems app meta-information, replacing complex diagrams with intuitive, faster app creation.

## Initial situation

OutSystems is a low-code platform for mobile and web enterprise applications. Its end-users relied on diagrams and drag-and-drop interfaces to define application logic — often confusing and hard to grasp, especially for new users.

## Approach

We eliminated manual drag-and-drop and diagram creation. Users now describe what they want to build or upload a document; our multi-agent system generates the meta-information needed for OutSystems. Users iteratively validate and adjust use cases, roles and screens — keeping full control throughout.

## Results

- More **intuitive approach** to building apps for non-technical users
- **Accurate, detailed use case generation** with planning, reflection and edge cases
- **Significantly faster app creation** vs. manual diagram definition
