# Discovery workshop agenda template

A one-day running order.
Adjust the timings, not the sequence: each phase consumes what the previous one produced.

| Time | Phase | Output |
|---|---|---|
| 09:00 | Arrivals, introductions, the one-sentence goal | Goal on the wall |
| 09:30 | Frame: what would be true if this succeeded | One-page problem statement, draft |
| 10:30 | Break | |
| 10:45 | Map: current state, box by box | Current-state map with owners |
| 12:30 | Lunch | |
| 13:15 | Map continued: integrations and data flows | Map completed |
| 14:30 | Cut: first delivery scope, parked list | Scope line, parked list |
| 15:30 | Break | |
| 15:45 | Commit: risks, owners, dates | Risk list |
| 16:30 | Read back: problem statement, scope, parked list, risks | Agreement in the room |
| 17:00 | Close | |

## Facilitator notes

- Read the parked list aloud before close. An item nobody objects to being parked is genuinely out of scope. An item that provokes an objection was never agreed.
- If the current-state map is not finished by the end of lunch, cut scope from the Cut phase rather than running over. A rushed risk list is worse than a short one.
